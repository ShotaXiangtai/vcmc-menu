# vcmc-menu

よく使うコマンドを GUI から実行できる、プレイヤー向けのメニュープラグインです。`/menu` で開きます。

- サーバーのコマンド（[コマンド一覧](https://www.vcmc.jp/commands.html)）、チェスト保護（[Bolt](https://github.com/pop4959/Bolt)）、資源ワールド（resource-core）、ハブ（vcmc-hubcommand）のプレイヤー向けコマンドをボタンにしています
- 管理者向けのコマンドは載せていません
- 名前が必要なコマンドは、オンラインのプレイヤーの一覧から選ぶか、入力欄に入力します
- ボタンの内容は `menu.yml` で変更できます。再起動は不要です
- config を編集しなくてもすべて動作します

> **サーバー上での動作はまだ確認していません。** 本番に入れる前に、[ゲーム内で確認してほしい項目](#ゲーム内で確認してほしい項目) をテストサーバーで確認してください。

## 動作環境

| 項目 | バージョン |
|---|---|
| サーバー | Folia 26.3（`folia-api 26.3.build.6-alpha` でビルド） |
| Java | 25 以上 |
| 必須プラグイン | なし |

ほかのプラグインのコマンドは名前で呼び出すだけなので、依存関係はありません。呼び出す先のプラグインが入っていないボタンを押すと、通常の「不明なコマンド」のメッセージが出ます。

## 導入手順

1. [Releases](../../releases) から `vcmc-menu-<バージョン>.jar` をダウンロードして、`plugins/` に入れます。
2. サーバーを起動します。`plugins/vcmc-menu/` に `menu.yml`、`messages.yml`、`lang` フォルダが作られます。

### 1.0.1 からの更新

jar を入れ替えるだけで動きます。`menu.yml` と `messages.yml` はそのまま使えます。`menu.yml` を編集している場合は、「多言語対応」も確認してください。

### 1.0.0 からの更新

1.0.1 では `/stream` と `/rec` を `via: client` に変更し、チェスト保護の画面を作り直して、説明文も見直しました。`plugins/vcmc-menu/menu.yml` は jar を入れ替えても上書きされないので、次のどちらかをしてください。

- `menu.yml` を編集していなければ、削除して `/menu reload` を実行します。
- 編集している場合は、jar 内の `menu.yml` を見ながら変更を反映して、`/menu reload` を実行します。

## コマンドと権限

| コマンド | 内容 | 権限 | 既定 |
|---|---|---|---|
| `/menu` | メニューを開く | `vcmcmenu.command.menu` | 全員 |
| `/menu reload` | `menu.yml`、`messages.yml`、`lang` フォルダを読み直す | `vcmcmenu.admin.reload` | OP |

## メニューの内容

メニューのボタンは、押したプレイヤーの権限で実行します。プレイヤーが打てないコマンドは、ボタンからも実行できません。

| 画面 | コマンド |
|---|---|
| 最初の画面 | `/hub` `/sit` `/lay` `/crawl` `/spin` `/co i` `/gchest` と、下の各画面へのボタン |
| 資源ワールド | `/main` `/resource overworld` `/resource nether` `/resource end` |
| チェスト保護 | `/bolt lock private\|display\|deposit\|withdrawal\|public` `/bolt unlock` `/bolt info` |
| チェスト保護: 使える人 | `/bolt edit add\|remove <名前>` `/bolt modify add\|remove normal group <グループ名>` `/bolt modify add\|remove normal password <パスワード>` |
| チェスト保護: 信頼する人 | `/bolt trust add\|remove player <名前>` `/bolt trust` |
| チェスト保護: グループ | `/bolt group create\|list\|delete <グループ名>` `/bolt group add\|remove <グループ名> <名前>` |
| チェスト保護: 所有権の譲渡 | `/bolt transfer <名前>` `/bolt requests list` `/bolt requests accept\|deny\|cancel <名前>` |
| チェスト保護: モード・その他 | `/bolt mode persist\|nolock\|nospam` `/bolt password <パスワード>` `/bolt help` `/bolt help <コマンド名>` |
| 投票 | `/vote` `/votegui` `/vote shop` `/vote help` `/vote total\|next\|last\|top\|streak\|best\|today` |
| 配信・撮影 | `/stream on\|off` `/rec on\|off` |

同じ機能のものは 1 つにまとめています。

- `/voteshop` は `/vote shop` の省略形です。
- `/lobby` と `/l` は `/hub` の別名です。
- `/bolt modify add|remove normal player <名前>` は `/bolt edit add|remove <名前>` と同じ動作です。
- `/resource`（引数なし）は、資源ワールドの画面と同じ 4 つを選ぶ GUI を開くだけです。

### `/hub`、`/stream`、`/rec` で確認ダイアログが出る理由

この 3 つは Velocity のコマンドです。サーバーから実行しても Velocity には届かないので、プレイヤーのクライアントから送る必要があります。クライアントに勝手にコマンドを送らせる手段はないので、確認ダイアログの「実行する」を押してもらいます。

### チェスト保護とコマンド一覧のページの違い

チェスト保護のボタンは、コマンド一覧のページではなく [Bolt の Wiki](https://github.com/pop4959/Bolt/wiki#commands) とソース（1.2.37）に合わせています。種類とモードの名前は、Bolt の日本語表示と同じです。

- ページの `/bolt mode no lock` と `no spam` は無効なモードになるので、`nolock` と `nospam` を使っています。
- `/bolt transfer` は、相手が承認して初めて譲渡されます（Bolt の既定の設定）。承認に使う `/bolt requests` のボタンを追加しました。
- ページにない `/bolt trust`（一覧）と、グループやパスワードをブロックに設定する `/bolt modify` のボタンを追加しました。

## 名前の入力

`type: player` の入力では、オンラインのプレイヤーの頭アイコンが並ぶ画面を開きます。

- 自分と、自分から見えないプレイヤー（バニッシュ中など）は一覧に出ません。
- 45 人を超えるとページが分かれます。
- 「名前を入力する」から、一覧にいない人も指定できます。

`type: text` の入力ではダイアログを開きます。空白を含む値、長すぎる値、チャットで打てない文字（`§` など）を含む値は受け付けず、ダイアログを開き直します。キャンセルや Esc で元の画面へ戻ります。

入力したパスワードはチャットに流れません。ただし、手で打ったときと同じく、コマンドとしてプラグインへ渡されます。

## メニューの編集

`menu.yml` を編集して `/menu reload` を実行してください。書式はファイルの先頭に書いてあります。例えば、名前を選んで実行するボタンは次のように書きます。

```yaml
trust-add:
  slot: 14
  icon: EMERALD
  name: "<green>全保護へのアクセスを許可"
  lore:
    - "<gray>自分の保護すべてへのアクセスを許可します"
  command: "bolt trust add player {player}"
  inputs:
    player:
      type: player
      label: "全保護へのアクセスを許可する人"
```

Velocity など、このサーバーの外にあるコマンドには `via: client` を付けてください。

不正な値はエラーログを出して、既定値を使うか、そのボタンだけを省きます。サーバーは止まりません。ファイルが読めないときや `main` 画面がないときは、起動中なら今のメニューを使い続け、起動時なら jar 内の既定のメニューを使います。

日本語のメッセージは `messages.yml`（MiniMessage 形式）で変更できます。空文字にすると送信しません。ほかの言語は「多言語対応」を参照してください。

## 多言語対応

プレイヤーのクライアントの言語設定に合わせて、メッセージを自動で切り替えます。ゲーム中に言語を変更すると、次のメッセージから反映されます。

| クライアントの言語 | 表示する言語 | 文面の場所 |
|---|---|---|
| 日本語 | 日本語 | `messages.yml` と `menu.yml` |
| English（各地域） | English | `lang/en.yml` |
| 简体中文 | 简体中文 | `lang/zh_cn.yml` |
| 繁體中文（台灣）、文言 | 繁體中文（台灣） | `lang/zh_tw.yml` |
| 繁體中文（香港） | 繁體中文（香港） | `lang/zh_hk.yml` |
| 上記以外 | English | `lang/en.yml` |

繁體中文（香港）の文面は広東語で書いています。コンソールへのメッセージとログは日本語のままです。

`lang` フォルダのファイルは初回起動時に作られます。編集して `/menu reload` を実行すると反映されます。ファイルに無いキーは jar 内の既定の文面を使います。

ボタンの翻訳は `lang` のファイルの `menu` にあります。構造は `menu.yml` と同じで、`title`、`name`、`lore`、`label` だけを書きます。`menu.yml` の文面を変えたり、ボタンを追加したりしたら、`lang` のファイルの同じ場所も変更してください。翻訳が無い文面は `menu.yml` の日本語で表示します。

種類とモードの名前は、English と简体中文は Bolt の表示に合わせ、繁體中文（台灣）と繁體中文（香港）はその繁体字にしています。

## テスト手順

### 自動テスト

```
./gradlew test
```

コマンドの雛形、入力値の検証、ページ分け、入力の順序、`menu.yml` の読み込み、翻訳ファイルのキーとプレースホルダーを確認します。同梱の `menu.yml` については、問題が出ないこと、サイト、Bolt、README のコマンドが過不足なく載っていること、管理者向けのコマンドが無いこと、説明文のコマンドと実行内容が一致することを確認します。

### 確認済みの項目

サーバーを起動しての確認はしていません。確認できているのは次の項目だけです。

- `folia-api 26.3.build.6-alpha` に対してコンパイルできる
- 自動テストがすべて通る
- Bolt 1.2.37 のソースと Wiki に照らして、サブコマンドの書式と、実行後にブロックのクリックが必要かどうかが正しい
- Folia 26.3 と Paper のソースを読んで、使っている API がプレイヤーのリージョンスレッドから呼べる

### ゲーム内で確認してほしい項目

**以下はサーバーとプレイヤー接続が必要なので、まだ一度も動かしていません。**

全般:

- [ ] `/menu` で開き、各画面の間を移動できる。戻るボタンと閉じるボタンが動く
- [ ] アイテムを持ち出せない（シフトクリック、ドラッグ、数字キー、Q キーも）
- [ ] 飾りのガラスにカーソルを乗せても説明が出ない。ツルハシに攻撃力などの表示が出ない
- [ ] ボタンをダブルクリックしても、`/bolt mode persist` などが 2 回実行されない
- [ ] コンソールから `/menu` を実行すると「プレイヤーのみ」と出る
- [ ] 実行中のコンソールに、スレッドのエラー（`Thread failed main thread check` など）が出ない

コマンド:

- [ ] 最初の画面のボタンがすべて動く。`/gchest` が開く
- [ ] `/votegui` と `/vote shop` で、それぞれの画面が開く
- [ ] `/main` と `/resource <ワールド>` で移動できる。移動先のワールドでメニューを開ける

Velocity のコマンド:

- [ ] `/hub` のボタンを押すと確認ダイアログが出て、「実行する」でロビーへ移動する
- [ ] `/stream on|off` と `/rec on|off` のボタンも確認ダイアログが出て、「実行する」で表示が切り替わる
- [ ] 「キャンセル」と Esc で元の画面へ戻る

チェスト保護:

- [ ] 各ロックのボタンを押してブロックをクリックすると、その種類で保護される
- [ ] `/bolt mode nolock` と `nospam` が ON / OFF できる
- [ ] 別のリージョンにいるプレイヤーも一覧に出て、頭アイコンのスキンが表示される
- [ ] 名前を選ぶと `/bolt edit add` などが動く。「名前を入力する」も動く
- [ ] `/bolt group add` で、グループ名の入力 → プレイヤーの選択の順に進む
- [ ] グループとパスワードをブロックに設定すると、ほかの人が使える
- [ ] 所有権の譲渡を出すと相手に通知が届き、相手が「譲渡を承認」で受け取れる
- [ ] 空白を含む値を入力すると、エラーを表示してダイアログを開き直す
- [ ] ダイアログを閉じたあと、チェスト画面に戻らない

`/menu reload`:

- [ ] `menu.yml` の変更が反映される
- [ ] 文法エラーのある `menu.yml` で実行すると、エラーログが出て今のメニューがそのまま動く

多言語対応:

- [ ] クライアントの言語を変えると、画面のタイトル、ボタン、ダイアログ、メッセージが切り替わる
- [ ] 翻訳の文面が長すぎて、説明の表示が崩れない

## 既知の制限

- **文字入力と、Velocity のコマンドの確認に Dialog を使っています。** Minecraft 1.21.6 以降の機能なので、ViaBackwards などで古いクライアントから接続している人や Geyser の人には、正しく表示されない可能性があります。
- **ボタンを押すと、コマンドはサーバー側で実行します（`via: client` を除く）。** `PlayerCommandPreprocessEvent` は発生しないので、このイベントでコマンドを制限するプラグインの制限は効きません。
- ボタンの ON / OFF の状態は表示しません。`/stream` や `/bolt mode` などの今の状態は、呼び出す先のプラグインのメッセージで確認してください。

## ビルド

Java 25 が必要です。

```
./gradlew build
```

`build/libs/vcmc-menu-1.1.0.jar` が生成されます（Kotlin 標準ライブラリを同梱）。

## リリース

`build.gradle.kts` の `version` を上げてコミットし、`v<バージョン>` のタグを push してください。GitHub Actions がテストとビルドを実行して、Releases に jar を載せます。タグと `version` が違うときは失敗します。リリースノートは Releases の画面か `gh release create` で書いてください。GitHub Actions はノートを変更しません。
